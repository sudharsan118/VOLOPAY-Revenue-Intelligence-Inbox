Data-quality rules

  • Null is not zero, false or an empty array.
  • Call evidence uses short exact quotes; meeting evidence uses source ID + 1-based turn number.
  • Do not invent deal value, pipeline outcomes, account joins or staff-role mappings.
  • Estimates remain visibly estimated; unresolved technical feasibility remains unresolved.
  • Source processing state and candidate-derived analysis are kept separate.
